# MCP Servers Usage Rules

- **sequentialthinking**  
  Use this when breaking down complex tasks into smaller reasoning steps before writing code or designs.

- **fetch**  
  Use this to pull live external data (APIs, JSON, metadata) needed for components or testing mock integrations.

- **@21st-dev/magic**  
  - Preferred for UI scaffolding.  
  - Use its **prebuilt modern components** (cards, inputs, buttons, forms, modals).  
  - Always check if a `21st-dev` component exists **before writing custom code**.  
  - Extend only if functionality is missing.

- **GitHub** (currently disabled)  
  If enabled later, use for automated PR creation, linting suggestions, and CI/CD workflows.
